Portfolio website of Kim Myeong-gi (KMG): https://kmg200164.github.io

Plain static site, no build step. `index.html` + `assets/`. Korean and English live side by side (`lang="ko"` / `lang="en"` spans); the button in the header switches them. `?lang=en` opens the English version.

How to update: see `UPDATING.md`.

Layout adapted from [Story by HTML5 UP](https://html5up.net/story), CC BY 3.0. The license is kept in `assets/STORY-LICENSE.txt` and the credit stays visible in the footer. Image links open a native `<dialog>` viewer; without JavaScript they open the image itself.
